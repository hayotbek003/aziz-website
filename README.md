# AZIZ WEBSITE — SaaS-конструктор интернет-магазинов в Telegram

Пользователь через Telegram-бота выбирает один из 10 шаблонов, смотрит демо всех страниц, получает собственный магазин
(первый — 7 дней бесплатно), редактирует дизайн и товары прямо в Telegram Web App и принимает заказы в личный Telegram.

**Стек:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · FastAPI · PostgreSQL (SQLAlchemy 2, asyncpg) · aiogram 3 · Telegram Web Apps API.
**Хостинг:** один проект Vercel — Next.js + Python-функция `api/index.py` (FastAPI). Все магазины — по адресу `https://<проект>.vercel.app/shop/<slug>`.

---

## Архитектура

```
Telegram ──► бот (aiogram 3, webhook /api/bot/webhook) ──┐
                                                        │
Telegram Web App / браузер ──► Next.js (Vercel)         ▼
   /                 лендинг + 10 шаблонов     /api/* ─► FastAPI (api/index.py, Python Function)
   /demo/<tpl>/...   демо-магазин шаблона               │  ├─ auth: проверка initData (HMAC), JWT
   /shop/<slug>/...  витрина клиента                    │  ├─ me: магазины, черновик/публикация, товары, медиа, статистика, оплата
   /panel/...        личный кабинет + редактор          │  ├─ admin: пользователи, магазины, платежи, шаблоны, тарифы
   /admin            админ-панель платформы             │  ├─ public: витрина, события, изображения
                                                        │  └─ cron: напоминания об окончании аренды
                                                        ▼
                                                   PostgreSQL
```

* **Один источник шаблонов** — `shared/templates.json` (базовый конфиг + 10 шаблонов + цветовые темы + тарифы). Его читают и frontend (демо, превью), и backend (создание магазина с демо-товарами).
* **Витрина** (`src/components/store`) — общий движок для всех 10 шаблонов: тема (цвета, шрифты, фон, скругления, стиль карточек), порядок и видимость блоков, страницы. Адаптивность — через **container queries**, поэтому один и тот же код корректно выглядит и на телефоне, и на ПК, и внутри рамки предпросмотра редактора.
* **Изоляция клиентов**: каждый эндпоинт кабинета проверяет `shop.owner_id == user.id` (`backend/deps.py`). Тема магазина применяется CSS-переменными к корню витрины — магазины не влияют друг на друга.
* **Черновик и публикация**: дизайн хранится в `shops.draft_config` и `shops.published_config` (JSONB). Покупатели видят только опубликованную версию; владелец может открыть черновик по подписанной ссылке предпросмотра. Товары/категории применяются сразу.
* **Сроки аренды контролирует сервер**: `shop_state()` вычисляет статус (`trial | active | expired | unpaid | blocked`) при каждом запросе витрины; неактивный магазин отдаёт экран «временно недоступен».
* **Заказы**: без корзины и встроенной оплаты — кнопка «Заказать в Telegram» открывает `t.me/<продавец>?text=<товар, цена, ссылка>`; продавцу дополнительно приходит уведомление от бота платформы.
* **Безопасность**: токен платформенного бота — только в env. Токены ботов продавцов шифруются Fernet (`ENCRYPTION_KEY`), хранятся в `shops.bot_token_enc` и никогда не отдаются во frontend. Вход в Web App — по подписи `initData` (HMAC-SHA256), с компьютера — одноразовая ссылка `/login` из бота. Webhook защищён `X-Telegram-Bot-Api-Secret-Token`, cron — `CRON_SECRET`.

## База данных (PostgreSQL)

| Таблица | Назначение |
|---|---|
| `users` | Telegram-пользователи: `telegram_id`, username, `is_admin`, `is_blocked`, `trial_used` |
| `shops` | Магазины: `owner_id`, `slug` (адрес), `template`, `draft_config`/`published_config` (JSONB), `trial_ends_at`, `paid_until`, `is_blocked`, `bot_token_enc`, `views` |
| `categories` | Категории магазина: имя, slug, иконка, картинка, описание, порядок |
| `products` | Товары: цена, старая цена, «от», описание, `specs` (JSONB), `images` (JSONB), популярный, наличие, количество |
| `media` | Загруженные изображения (bytea, сжаты на клиенте до 1600px WebP) |
| `events` | Статистика: `view`, `product_view`, `order_click` |
| `payments` | Платежи аренды: Telegram Stars или перевод (подтверждает админ) |
| `template_settings` | Управление шаблонами из админки (вкл/выкл, порядок, название) |
| `app_settings` | Тарифы аренды и прочие настройки |
| `login_tokens` | Одноразовые ссылки входа с компьютера |
| `bot_states` | FSM-состояния диалога бота (serverless не хранит память между вызовами) |

Таблицы создаются автоматически при первом запросе (`backend/db.py → ensure_db`).

## Возможности

**Бот** (`backend/bot/handlers.py`): START → «Создать сайт» → выбор типа (10 кнопок) → карточка шаблона с листанием ◀ ▶ и кнопкой «Смотреть демо» (Web App) → «Выбрать этот шаблон» → название → ссылка (ID) → Telegram для заказов → «Сайт успешно создан!» с кнопками «Открыть сайт», «Редактировать», «Продлить аренду». Также: «Мои сайты», оплата аренды Telegram Stars (счёт → pre_checkout → successful_payment → срок продлевается автоматически), `/login`, `/admin`, напоминания об окончании срока.

**Витрина каждого магазина** — страницы: Главная, Каталог (поиск, фильтр по категориям, сортировка, «только в наличии»), Категория, Товар (галерея, характеристики, похожие, «Заказать в Telegram»), О магазине, Доставка, FAQ, Контакты, Избранное. Русский / узбекский интерфейс.

**Визуальный редактор** (`/panel/shop/<id>/editor`): слева — инструменты (Дизайн, Главная, Блоки, Страницы, Магазин), справа — живой предпросмотр (телефон / ПК, выбор страницы). Логотип, название, 13 готовых тем, 6 цветов, 12 шрифтов, фон (цвет/градиент/свечение/фото), скругления, стиль карточек, фото главной, баннеры, преимущества, порядок и видимость блоков, тексты всех страниц, шаблон сообщения заказа. Кнопки: «Сохранить», «Предпросмотр», «Опубликовать», «Отменить изменения», шаг назад/вперёд (Ctrl+Z / Ctrl+Shift+Z), Ctrl+S. На телефоне — переключатель «Настройки / Просмотр».

**Кабинет**: товары (несколько фото, порядок фото, цена, старая цена, описание, характеристики, категория, популярный, наличие, количество, дублирование, удаление), категории, настройки (адрес, контакты, соцсети, язык, валюта, подключение своего бота), статистика, срок аренды и оплата.

**Админ-панель** (`/admin`): обзор и выручка, все магазины (поиск, фильтр по статусу, блокировка/активация, продление +7/+30 дней), пользователи (блокировка), платежи (подтверждение/отклонение переводов), шаблоны (вкл/выкл, порядок, название, описание), тарифы, настройка webhook бота.

## Локальный запуск

```bash
npm install
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt     # Windows (Linux/macOS: .venv/bin/pip)
cp .env.example .env    # для локального режима: DEV_MODE=true, JWT_SECRET=любая строка
npm run dev             # Next.js :3000 + FastAPI :8000
```

* Без `DATABASE_URL` используется локальный SQLite-файл (только для разработки). Для PostgreSQL укажите `DATABASE_URL=postgresql://...`.
* В `DEV_MODE=true` на странице `/panel` есть кнопка «Войти как тестовый пользователь» (первый вошедший становится админом, если `ADMIN_TELEGRAM_IDS` пуст).
* Бот локально: укажите `BOT_TOKEN` и запустите `npm run bot` (polling). Кнопки Web App требуют HTTPS — для теста внутри Telegram используйте туннель (например, cloudflared) и пропишите его адрес в `WEBAPP_URL`.
* Сквозная проверка API: `python scripts/smoke_test.py` (85 проверок: изоляция клиентов, черновик/публикация, пробный период, оплата, админка, подпись initData).

## Деплой на Vercel (один проект для всех магазинов)

1. Создайте бота у @BotFather и получите `BOT_TOKEN`. Для оплаты Telegram Stars платёжный провайдер не нужен.
2. Создайте PostgreSQL (Neon, Supabase или Vercel Postgres) и скопируйте строку подключения.
3. Импортируйте репозиторий в Vercel (Framework: Next.js). Python-функция `api/index.py` и `requirements.txt` подхватываются автоматически (см. `vercel.json`).
4. Задайте переменные окружения из `.env.example`: `DATABASE_URL`, `BOT_TOKEN`, `WEBAPP_URL` (адрес проекта), `JWT_SECRET`, `ENCRYPTION_KEY`, `WEBHOOK_SECRET`, `CRON_SECRET`, `ADMIN_TELEGRAM_IDS`.
5. Задеплойте, откройте `https://<проект>.vercel.app/panel`, войдите через бота (`/login`) под админским Telegram ID и в `/admin` нажмите **«Настроить бота»** — регистрируются webhook, команды и кнопка меню Web App.
6. Vercel Cron раз в день вызывает `/api/cron/daily` (напоминания об окончании аренды).

Покупка домена не требуется: все магазины живут на одном домене — `https://<проект>.vercel.app/shop/<slug>`.

## Что стоит сделать перед большим трафиком

* Перенести изображения из PostgreSQL в объектное хранилище (Vercel Blob / S3) — сейчас они хранятся в таблице `media` и кешируются браузером/CDN навсегда.
* Добавить миграции Alembic вместо `create_all` для будущих изменений схемы.
* Ограничение частоты запросов на публичные события статистики.
