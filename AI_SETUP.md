# Подключение ИИ-консультанта и автоответчика

## 1. Ключ Claude API (нужен для обоих)
1. Зайдите на https://console.anthropic.com → **API Keys** → **Create Key**. Пополните баланс в **Billing**.
2. Добавьте ключ на Vercel (ключ вставляете сами, когда команда спросит):
   ```
   npx vercel env add ANTHROPIC_API_KEY production
   npx vercel --prod --yes
   ```
3. Добавьте тот же ключ в файл `.env` в папке проекта строкой `ANTHROPIC_API_KEY=...` (для автоответчика).

После этого бот @drop_uzb_bot сам отвечает на любые текстовые сообщения. Когда нужен человек
(скидка, оплата переводом, жалоба), вам придёт сообщение «🙋 Нужен владелец».

Настройки (необязательно, переменные окружения): `AZIZ_AI_MODEL` (по умолчанию `claude-opus-5-5`),
`AZIZ_AI_EFFORT` (по умолчанию `low`).

## 2. Автоответчик в личном Telegram
1. Откройте https://my.telegram.org → войдите по номеру → **API development tools** → создайте приложение.
   Скопируйте `api_id` и `api_hash` в `.env`:
   ```
   TG_API_ID=1234567
   TG_API_HASH=abcdef...
   ```
2. Установите зависимости и сначала запустите в режиме проверки (ничего не отправляет):
   ```
   .venv\Scripts\pip install -r requirements-userbot.txt
   .venv\Scripts\python -m scripts.userbot.auto_reply --dry-run
   ```
   При первом запуске введите свой номер и код из Telegram — **сами, в этом окне**. Никому их не пересылайте.
3. Когда в логах видно, что ответы адекватные, запустите по-настоящему:
   ```
   .venv\Scripts\python -m scripts.userbot.auto_reply
   ```
   Работает, пока открыто окно и включён компьютер.

Правила автоответчика: никому не пишет первым; отвечает только проверенным продавцам из `leads.csv`,
которые ответили на ваше сообщение; если вы сами написали в чат — молчит там 12 часов; лимит 60 ответов в день.
Файл `scripts/userbot/aziz_owner.session` — это доступ к вашему аккаунту: не отправляйте его никому.
Чтобы отключить доступ: Telegram → Настройки → Устройства → завершить сеанс автоответчика.
