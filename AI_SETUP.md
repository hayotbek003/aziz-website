# Автоответчики: бот и личный Telegram

По умолчанию всё работает **бесплатно, без ключей ИИ**: ответы подбираются по ключевым словам
(русский и узбекский) — цена, бесплатный период, как начать, шаблоны, заказы, домен, товары, свой бот.
Скидки, оплата переводом, жалобы, просьба позвать человека и всё непонятное передаются вам.
Тексты ответов и ключевые слова — в `backend/faq_assistant.py`.

## 1. Бот @drop_uzb_bot
Уже работает на сервере: отвечает на любое текстовое сообщение. Когда нужен человек, вам в Telegram
приходит «🙋 Нужен владелец» со ссылкой на чат. Ничего настраивать не нужно.

## 2. Автоответчик в личном Telegram
Нужны бесплатные данные приложения Telegram (это не платный API):
1. Откройте https://my.telegram.org → войдите по номеру → **API development tools** → создайте приложение.
   Впишите в файл `.env` в папке проекта:
   ```
   TG_API_ID=1234567
   TG_API_HASH=abcdef...
   ```
2. Установите зависимости и сначала запустите в режиме проверки (ничего не отправляет):
   ```
   .venv\Scripts\pip install -r requirements-userbot.txt
   .venv\Scripts\python -m scripts.userbot.auto_reply --dry-run
   ```
   При первом запуске введите свой номер и код из Telegram — **сами, в этом окне**. Никому их не пересылайте.
3. Когда в логах видно, что ответы правильные, запустите по-настоящему:
   ```
   .venv\Scripts\python -m scripts.userbot.auto_reply
   ```
   Работает, пока открыто окно и включён компьютер.

Правила: никому не пишет первым; отвечает только проверенным продавцам из `leads.csv`, которые ответили
на ваше сообщение; если вы сами написали в чат — молчит там 12 часов; лимит 60 ответов в день;
«не интересно / kerak emas» — вежливо прощается и больше не отвечает.
Файл `scripts/userbot/aziz_owner.session` — это доступ к вашему аккаунту: не отправляйте его никому.
Отключить: Telegram → Настройки → Устройства → завершить сеанс автоответчика.

## Необязательно: умные ответы через Claude
Если когда-нибудь захотите живые ответы ИИ вместо готовых текстов — добавьте `ANTHROPIC_API_KEY`
(платно, console.anthropic.com) на Vercel (`npx vercel env add ANTHROPIC_API_KEY production`, затем
`npx vercel --prod --yes`) и в `.env`. Без ключа всё продолжает работать бесплатно.
